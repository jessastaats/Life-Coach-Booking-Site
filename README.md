# North & Bloom Life Coaching — Booking Website

A premium, responsive service-business website and interactive appointment-booking experience created as a portfolio project.

## Project goals

This concept demonstrates how a life coach, consultant, wellness professional, or other appointment-based business can move a visitor from first impression to service selection and booking in one cohesive experience.

## Features

- Premium responsive landing page for desktop and mobile
- Distinct editorial brand direction using custom CSS artwork rather than stock imagery
- Service cards with contextual booking actions
- Interactive appointment scheduler
- Dynamically generated upcoming weekday availability
- Date and time selection states
- Client intake form
- Booking summary and confirmation state
- FAQ accordion
- Smooth in-page navigation
- Responsive layouts and touch-friendly controls
- Clear coaching vs. therapy disclaimer language
- Portfolio disclosure for demo bookings

## Booking integration

The included scheduler is a front-end demonstration and intentionally does not create real appointments or collect payment. It is structured so a production version can be connected to:

- Calendly
- Acuity Scheduling
- Cal.com
- Google Calendar API
- Microsoft Bookings
- Square Appointments
- Stripe + custom scheduling backend

The front-end service, date, time, and intake states can be passed to a scheduling API or replaced with an embedded provider while retaining the surrounding branded booking experience.
